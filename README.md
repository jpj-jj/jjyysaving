# กระปุกบ้านเรา

เว็บออมเงินในบ้านสำหรับ JOOPJANG และ YAYA เปิดใช้งานผ่าน GitHub Pages

ข้อมูลการออม ข้อความ สลิป และรูปโปรไฟล์ เก็บอยู่ใน Google Sheet และ Google Drive ของเจ้าของ ไม่ได้อยู่ใน repo นี้

ไฟล์ `Code.gs` (โค้ดหลังบ้าน) ไม่ได้อยู่ใน repo นี้ ให้วางไว้ใน Apps Script ของ Google Sheet โดยตรง
